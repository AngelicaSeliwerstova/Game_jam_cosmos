# Двери и шлюз — проверка 6 ноября 2026

Godot 4.7.2.stable, Windows, Compatibility / OpenGL 3.3.
Проверяется настоящая игровая сцена с игроком, коллизиями, датчиками Area3D,
лучом взаимодействия и событиями E. Это автоматический графический прогон.

## Проверено

`tools/verify_doors.gd`: **48 проверок, 0 ошибок**.

- В сцене девять дверей: две автоматические, пять распашных комнатных,
  внутренняя и наружная двери шлюза. Декоративных `ParkedInnerDoor` в проходе нет.
- Автоматические двери изначально закрыты и физически препятствуют движению.
  Оба датчика открывают их при подходе, створки уходят в разные стороны,
  а капсула игрока свободно проходит по центру. После ухода двери закрываются.
- Игрок может пробежать через автоматическую дверь на Shift без E.
  Дверь остаётся открытой, пока персонаж находится в проёме.
- Луч находит дверь комнаты с обеих сторон. E открывает и закрывает её;
  при открытии выбирается сторона от игрока. Коллизия следует за створкой.
  Пауза останавливает анимацию; дверь не закрывается на игроке в проёме.
- Нажатие E на самой створке шлюза не открывает её: требуется настоящая кнопка.
  Проверены луч и подсказка HUD у всех четырёх панелей: вход со станции,
  выход из камеры, вход с Луны и возвращение из камеры на станцию.
- После первой кнопки открывается только внутренняя дверь. Вторая кнопка
  сначала закрывает внутреннюю, затем открывает наружную. В каждом проверяемом
  физическом кадре хотя бы одна из дверей полностью закрыта.
- Если игрок блокирует закрытие внутренней двери, наружная остаётся закрытой.
  После освобождения проёма цикл продолжается.
- Пройден полный маршрут с вводом движения и E: станция → шлюз → пандус → Луна,
  затем наружная кнопка → шлюз → внутренняя кнопка → станция.
  Между нажатием кнопок игрок идёт физически; телепортации между дверями нет.
- После выхода наружная дверь автоматически закрывается с учётом четырёх
  секунд свободного проёма и времени движения створок.
- Получены и просмотрены снимки закрытой/открытой автоматической двери и шлюза.
  Подсказка управления разбита на две строки.
- Автоматические двери переделаны в стеновые секции: наружные боковые короба
  удалены, створки прячутся между обшивками, материал совпадает со стеной.
  Проём сохраняет ширину 1,8 м и проходится бегом.

Дополнительно `tools/verify_station.gd`: **80 проверок, 0 ошибок**.
Его архитектурные маршруты проверяются с предварительно открытыми дверями;
взаимодействия и блокировки отдельно покрывает прогон дверей.
В старом прогоне сохранены проверки грядок, осмотра, бега, прыжка, паузы и меню.

## Ограничения

Проверка автоматическая, без ручного прохождения клавиатурой и мышью.
Давление, кислород и проверка скафандра не симулируются; реализована
блокировка одновременного открытия. Новые двери в Web-сборке не проверялись.
Сообщение песочницы о системном хранилище сертификатов не влияет на локальные проверки.
