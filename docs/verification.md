# Проверка технической основы

Дата: 3 ноября 2026. Godot: `4.7.2.stable.official.ed1daf0bf`, стандартная
официальная портативная Windows x64 версия. Установленной версии в PATH,
стандартных папках программ, Downloads и Dev/Tools не обнаружено.

## Выполнено

- Импорт проекта: `godot --headless --path . --editor --import --quit`.
  Godot зарегистрировал глобальные классы и создал `.gd.uid` для скриптов;
  ошибок разбора сцен, ресурсов или GDScript не обнаружено.
- Запуск основной сцены: `godot --headless --path . --quit-after 3`.
- Отдельный **графический**, не headless, запуск с Compatibility:
  OpenGL 3.3, Intel UHD Graphics. Временный проверочный скрипт в игнорируемой
  `.tools/` отправлял события мыши и Escape в настоящий viewport Godot,
  проходя GUI и `_unhandled_input`, и сохранял кадры `ViewportTexture`.
  Проверка не подменяла выбор прямым вызовом обработчика места.
- Меню → «Начать» → теплица; шесть мест и соответствующие номера в панели;
  снятие предыдущего выделения и повторный клик по выбранному месту.
- Пауза кнопкой; `SceneTree.paused == true`, сцена перестаёт обрабатываться,
  меню паузы остаётся активным. Клик по месту под оверлеем не меняет выбор.
- Продолжение кнопкой, открытие и закрытие паузы через Escape, возврат
  в меню из паузы и повторный вход с `paused == false`.
- Изменение настоящего размера окна на 1920×1080 и 1024×768; выбор всех
  шести мест при каждом размере. При 1280×720 и 1920×1080 виртуальный размер
  интерфейса — 1280×720, при 1024×768 — 1280×960.
- Визуальный просмотр PNG реального кадра: главное меню, теплица и пауза;
  размеры теплицы 1280×720, 1920×1080, 1024×768. Все шесть мест различимы,
  текст с кириллицей читаем, HUD не перекрывает посадочные места.

## Проверка после перехода на SubViewport

Повторены импорт и графический прогон после изменения вывода 3D.
Итог последнего прогона: **0 неуспешных проверок**, ошибок сцен и GDScript нет.

- Фактический размер текстуры 3D проверен через `get_image().get_size()`:
  **640×360** при каждом размере окна. HUD принадлежит корневому viewport окна,
  изображение 3D использует nearest. Материалы помещения, мест и растения
  явно настроены на nearest; у листьев и верхушки растения 8 радиальных сегментов.
- Для кликов использованы независимо вычисленные экранные координаты:
  проекция точки места камерой 640×360 → ожидаемый масштаб и поля окна.
  Выбраны все шесть мест при 1280×720, 1920×1080, 1024×768 и 1600×720.
  Подтверждены номер в панели, единственное выделение и повторный выбор.
- При 1024×768 изображение 3D занимает 1024×576 с полями по 96 пикселей
  сверху и снизу; при 1600×720 — 1280×720 с полями по 160 пикселей слева
  и справа. Проверены сохранение 16:9, центрирование и игнорирование кликов
  во всех четырёх полях.
- Повторены пауза кнопкой и Escape, блокировка выбора под оверлеем,
  продолжение, возврат в меню и повторный вход. Изменение размера окна
  во время паузы сохраняет центрирование изображения.
- Просмотрены обновлённые PNG реальной OpenGL-отрисовки теплицы при всех
  четырёх размерах и паузы при 1024×768: 3D пикселизировано, текст HUD
  и паузы чёткий, посадочные места не перекрыты интерфейсом.

3D-мир находится в `scenes/greenhouse/greenhouse_world.tscn`, вывод — в
`scenes/greenhouse/greenhouse.tscn`. Камера, свет, меши и коллизии остаются
частью полноценной 3D-сцены. Web-проверка по-прежнему не выполнялась.

Проверочные скрипты, снимки, скачанный редактор и его настройки находятся
только в `.tools/`, исключённой из Git и из импорта Godot через `.gdignore`.
Формальные тесты, повторяющие код кнопок, в проект не добавлялись.

## Ограничения

- Шаблоны экспорта не установлены: Web-пресет подготовлен, но экспорт
  и браузерный запуск через HTTP не выполнялись. Проверка Web-ветки,
  скрывающей «Выход», остаётся частью браузерной проверки.
- Инструмент управления Windows UI не подключился (`native pipe unavailable`).
  Поэтому физические клики через рабочий стол, нажатия F5/F6 в редакторе
  и ручное перетаскивание границ окна не проверялись. Ввод и размеры окна
  проверены программно внутри графического запуска Godot; снимки просмотрены
  визуально. Headless-запуск не использовался как доказательство отображения.
- Песочница не предоставила Godot обычный доступ к `user://` и системному
  хранилищу сертификатов Windows. Движок сообщил об ошибках создания
  пользовательских логов/кэша и чтения сертификатов. Для редактора включён
  портативный режим (`_sc_`), лог графической проверки направлен в `.tools/`.
  Эти сообщения окружения не помешали импорту, графическому запуску и прогону;
  ошибок сцен и скриптов при них не обнаружено. Запуск вне песочницы не проверялся.
- Настольный экспорт и публикация не выполнялись. Репозиторий Git в исходной
  папке отсутствовал; Git не инициализировался, коммит не создавался.
