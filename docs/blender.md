# Экспорт станции в Blender

Для переноса используется **glTF Binary (`.glb`)**. Экспортируется
`scenes/greenhouse/greenhouse_world.tscn`: станция, купол, комнаты, мебель,
все шесть грядок, грунт, камни, звёзды, камеры и поддерживаемый свет.
Текстуры включаются в GLB, отдельные изображения переносить не нужно.

## Готовый файл

В локальной рабочей копии после экспорта:

```text
C:\Users\tsostanov\Dev\cosmos\build\blender\lunar_station.glb
```

Папка `build/` исключена из Git. После скачивания исходников с GitHub
создай GLB одним из способов ниже.

## Экспорт кнопками в Godot

1. Открой проект и сцену **`scenes/greenhouse/greenhouse_world.tscn`**.
   Нужна именно 3D-сцена мира: `greenhouse.tscn` содержит интерфейс и SubViewport.
2. Убедись, что купол и крыши видны, если нужен полный вариант станции.
3. Выбери **Scene → Export As… → glTF 2.0 Scene…**
   («Сцена → Экспортировать как… → Сцена glTF 2.0…»).
4. Выбери бинарный формат **`.glb`** и сохрани файл, например `lunar_station.glb`.
5. Если есть настройка **Visibility Mode**, выбери **Exclude**:
   скрытые контуры выделения и неактивные заглушки растений не попадут в Blender.

Это экспорт сцены, поэтому меню **Project → Export** и игровые экспортные
шаблоны здесь не нужны.

## Экспорт командой

Из корня проекта, если `godot` доступен в PATH:

```sh
godot --headless --path . --script res://tools/export_station_glb.gd
```

Для портативного Godot в исходной рабочей копии, из PowerShell:

```powershell
& .\.tools\godot\Godot_v4.7.2-stable_win64_console.exe --headless --path . --log-file .tools/blender-export.log --script res://tools/export_station_glb.gd
```

Результат: **`build/blender/lunar_station.glb`**.
Команда перезаписывает этот экспорт. Исходная `.tscn` не меняется.

## Открытие в Blender

1. Открой Blender и создай пустой файл через **File → New → General**.
2. Удали стартовые куб, камеру и лампу: в 3D-виде нажми **A**, затем **X → Delete**.
3. Выбери **File → Import → glTF 2.0 (.glb/.gltf)**.
4. Укажи `lunar_station.glb` и нажми **Import glTF 2.0**.
5. Для цветов и текстур включи **Material Preview** в правом верхнем углу 3D-вида.
6. В Outliner раскрой `LunarStation`: комнаты, предметы и их геометрия
   сохраняют иерархию. Выдели нужный объект и нажми **Numpad .** для приближения.
7. Сохрани результат: **File → Save As… → `lunar_station.blend`**.

Для просмотра интерьера скрой соответствующие узлы `Roof` и `Dome`
через Outliner. При работе со станцией можно временно скрыть `Exterior`:
большой грунт и удалённые звёзды мешают кадрированию всей сцены.

## Что переносится

Переносятся сетки, расположение объектов, UV, поддерживаемые материалы,
текстуры, камеры и источники света glTF. Геометрия остаётся разбитой на объекты;
это не объединённая модель и не процедурные примитивы Blender.

GDScript, управление игроком, интерфейс, логика грядок, коллизии Godot,
WorldEnvironment и пикселизация не становятся рабочими системами Blender.
Label3D не следует считать редактируемым текстом Blender: таблички может
потребоваться восстановить текстовыми объектами. Освещение и прозрачность
могут выглядеть иначе; вид из игры автоматически не воспроизводится.

Blender не найден в стандартных путях этой рабочей среды; сохранение `.blend`
и визуальный просмотр непосредственно в Blender здесь не выполнялись.

[импорт glTF в Blender](https://docs.blender.org/manual/en/2.90/addons/import_export/scene_gltf2.html).
